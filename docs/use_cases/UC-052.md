# Use Case: Canary a Backend and Inject Chaos by Hand

## Overview

**Use Case ID:** UC-052
**Use Case Name:** Canary a Backend and Inject Chaos by Hand
**Primary Actor:** Operator
**Goal:** Move chosen controllers to another backend, or inject faults, with one HTTP call
**Status:** Implemented
**Requirements:** FR-006, FR-070, FR-073

## Preconditions

- The connect-proxy runs with the flag directory mounted.

## Main Success Scenario

1. Operator calls `POST /canary/rust?fraction=N` on the connect-proxy.
2. System rewrites `bluetooth_backend` in `controller.json` with fractional targeting on the controller serial (`fraction` 1 to 100, default 100; at 100 it sets the default variant and clears the targeting instead). `/canary/python` and `/canary/status` work the same way.
3. flagd reloads; the controller manager routes the selected controllers to the rust adapter on its next cycle.
4. Operator watches the backend comparison dashboard and `controller_routing_decisions_total`.
5. Operator calls `POST /canary/rollback` to return everyone to python.

## Alternative Flows

### A1: Inject chaos

**Trigger:** Operator calls `POST /chaos/{poll-drop|accel-spike|led-failure|disconnect}?fraction=N` instead of a canary (step 1)
**Flow:**

1. System rewrites `chaos_fault_type` (fractional targeting) in `controller.json`.
2. The chaos adapter injects the fault for the targeted controllers; `controller_chaos_faults_injected_total` counts them. The chaos adapter wraps only real (non-mock) adapters, and the controller manager decides at startup whether to wrap them (only when flagd was reachable then), so chaos has no effect on mock controllers or when flagd was down at startup.
3. `POST /chaos/reset` restores `none`; `/chaos/status` shows the current fault.
4. Use case ends.

### A2: Through envoy

**Trigger:** Operator calls `/canary/*` through the host entry point (port 80) (step 1)
**Flow:**

1. Envoy has no `/canary/` route; the request reaches the dashboard instead (D-B3). Call the connect-proxy from inside the network, or use `/chaos/`, which is routed.
2. Use case ends.

## Postconditions

### Success Postconditions

- The chosen controllers use the requested backend or fault.

### Failure Postconditions

- The flag file is unchanged.

## Business Rules

### BR-001: Manual canary wins

Per-serial `bluetooth_backend` targeting takes precedence over the agent's rollout (UC-050).

**Code / tests:** `services/connect-proxy/canary.go`, `chaos.go`, `services/controller_manager/backend_factory.py` (`_maybe_wrap_chaos`), `services/controller_manager/multiplexer/multiplexer_backend.py` (`_resolve_adapter_for_serial`), `chaos_adapter.py`; tests `services/controller_manager/tests/` (the connect-proxy handlers have no tests).
