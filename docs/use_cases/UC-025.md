# Use Case: Play a 1v1 Format

## Overview

**Use Case ID:** UC-025
**Use Case Name:** Play a 1v1 Format (Tournament, Fight Club)
**Primary Actor:** Player
**Goal:** Win duels: become tournament champion or the Fight Club leader
**Status:** Implemented
**Requirements:** FR-025, FR-033

## Preconditions

- A Tournament or Fight Club game was started with at least two players (UC-010).

## Main Success Scenario (Tournament)

1. System builds a single-elimination bracket padded to a power of two with byes and plays `tournament_intro`.
2. For each match System publishes `match_start`; both players are invincible for `invincibility_seconds` (default 4 s).
3. The first player to exceed the threshold loses the match (`match_end`); waiting players watch.
4. After `tournament.time_between_matches_seconds` (default 5 s) the next match starts.
5. When one player remains, System publishes `tournament_champion` and `game_ended`.

## Alternative Flows

### A1: Match timeout

**Trigger:** Nobody loses within `tournament.match_seconds` (default 22 s) (step 3)
**Flow:**

1. System picks a random winner.
2. Use case continues at step 4.

### A2: Fight Club

**Trigger:** Mode is FightClub (step 1)
**Flow:**

1. System queues players: the defender (red) faces a challenger (green); others wait dimmed.
2. Each round lasts `fight_club.round_seconds` (default 22 s) with 4 s invincibility. The winner stays and scores; on timeout both go to the back of the queue.
3. After `fight_club.min_rounds` (default 10) rounds, the game ends if one player leads; otherwise a face-off decides.
4. System publishes `game_ended`.

### A3: No winner

**Trigger:** No champion can be determined (Tournament step 5)
**Flow:**

1. System publishes `tournament_no_winner`.

## Postconditions

### Success Postconditions

- The champion or leader is in the event stream; the session is ENDED.

### Failure Postconditions

- `game_error` ends the session.

## Business Rules

### BR-001: Invincibility composes with agent shields

A player cannot die while `now < max(agent shield, match invincibility)` (#817).

### BR-002: Fixed tempo

Both modes run their own game loop without tempo changes (D-G3). Fight Club uses a fixed EMA weight (D-G9).
