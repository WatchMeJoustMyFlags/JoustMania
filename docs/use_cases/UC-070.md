# Use Case: Present the Talk Demo

## Overview

**Use Case ID:** UC-070
**Use Case Name:** Present the Talk Demo ("Two Standards Walk Into an Agent")
**Primary Actor:** Presenter
**Goal:** Show live that OpenTelemetry is the agent's nervous system and OpenFeature its will
**Status:** Implemented
**Requirements:** FR-090, FR-091, FR-092, FR-093, FR-094, FR-045, FR-042, FR-071, FR-072, C-004

## Preconditions

- Demo stack up: `make dry-run` (mock controllers, agent, seeded experiment) or the Pi stage stack with real controllers.
- API keys in `.env.local`; `IMAGE_TAG=latest` (the tracked `.env` pins an older release).
- Pre-flight check clean (`scripts/talk-preflight.sh`, in PR #1256).

## Main Success Scenario

1. Presenter enables the agent (`scripts/agent-dryrun-enable.sh on` or `agent-killswitch.sh on`) and starts a game (or `tools/demo/demo_driver.py --scenario ...`).
2. **Observe:** Presenter shows the game trace in Jaeger and the dashboard Agent tab; `agent.decide` spans appear inside the game trace.
3. **Act:** Presenter turns `interventions_enabled` on and widens `interventions_allowed`; interventions appear in the game and the trace.
4. **Switch the model:** Presenter runs `scripts/agent-backend.sh jev` (primary, ≈ 250 ms per decision), then `claude sonnet` (the backup), optionally `openai`, and `rules`; the next decisions show the new backend (UC-044).
5. **Permissions:** Presenter narrows `interventions_allowed` or flips the kill switch; decisions turn into `noop` / blocked / `discarded` (UC-045).
6. **Degrade:** Presenter cuts the network; decisions fall back to rules (`fallback_reason` timeout or error) and the game keeps playing (UC-040 A2).
7. Presenter resets the flags to baseline.

## Alternative Flows

### A1: Infrastructure beat (optional)

**Trigger:** Stage stack with a real controller on the python adapter
**Flow:**

1. Presenter starts a progressive rollout to `unstable` (UC-050); the agent expands, detects the violation and rolls back (UC-051).

### A2: Experiment beat

**Trigger:** Dry-run stack with the seeded experiment
**Flow:**

1. Presenter shows the Experiments tab and `/experiments` dossier filling up and the verdict (UC-043).

### A3: Remote decisions time out

**Trigger:** A Claude call exceeds `decision.claude.timeout_ms` (default 5000 ms since PR #1257; warm calls measured ≈ 2.7 to 3.0 s, cold calls up to 5.5 s before #1257)
**Flow:**

1. Decisions show `fallback` with `timeout`; select `patient` (8000 ms) or switch to Jev.

### A4: Budget exhausted

**Trigger:** The default budget of 6 calls per minute runs out
**Flow:**

1. Decisions fall back with `llm_budget_exhausted`; select the `stage` variant of `llm.max_requests_per_minute` (30 per minute, PR #1257) or set `AGENT_LLM_MAX_REQUESTS_PER_MINUTE` in `.env.local`.

### A5: Second vendor not configured

**Trigger:** `decision.openai.model` has only an empty variant (step 4)
**Flow:**

1. `openai` falls back with `backend_unavailable` until model and base URL variants are added.

## Postconditions

### Success Postconditions

- Every beat produced a visible effect in the game, the dashboard and Jaeger; flags are back at baseline.

### Failure Postconditions

- The game kept playing on rules.
