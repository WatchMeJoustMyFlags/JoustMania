# Use Case: Force-End a Game

## Overview

**Use Case ID:** UC-027
**Use Case Name:** Force-End a Game
**Primary Actor:** Operator
**Goal:** Stop a running game immediately
**Status:** Tested
**Requirements:** FR-028

## Preconditions

- A game session is STARTING or RUNNING.

## Main Success Scenario

1. Operator presses Stop in the dashboard (or calls ForceEndGame with a reason and optionally a game id).
2. System finds the target session (the primary game when no id is given).
3. System stops the game loop, waits up to 2 s for it to finish, sets the session to ENDED and publishes `game_force_ended` with the reason.
4. The menu restores the lobby (for the primary game).

## Alternative Flows

### A1: Unknown game id

**Trigger:** No session has the given id (step 2)
**Flow:**

1. System returns an error; nothing changes.

### A2: Game already ending

**Trigger:** The session is not STARTING or RUNNING (step 2)
**Flow:**

1. System does nothing.

### A3: Agent ends the game

**Trigger:** The agent applies `end_game` (UC-040)
**Flow:**

1. System ends the game through the same path.

## Postconditions

### Success Postconditions

- The session is ENDED and retired; the lobby is available.

### Failure Postconditions

- The session continues.

## Business Rules

### BR-001: Shadow games by id

Shadow games are ended only by explicit game id; an empty id targets the primary game.
