###   BREAKING CHANGES

* **agent:** the experiment seed is one `experiment_seed` flag ([#1907](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1907)) (#1964)
* **agent:** dynamic experiment settings are flags; the built-in denylist is a floor ([#1907](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1907)) (#1960)
* **agent:** remove AGENT_FITNESS_STORE_CAPACITY and AGENT_MAX_SHADOW_GAMES ([#1907](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1907)) (#1953)
* **agent:** the agent ignores AGENT_EXPERIMENTS_ENABLED, AGENT_EXPERIMENT_DYNAMIC_ENABLED, AGENT_EXPERIMENT_TICK_SECONDS, AGENT_EXPERIMENT_COMPLETED_GRACE_SECONDS, AGENT_VERDICT_MIN_N, AGENT_VERDICT_MIN_PAIRS and AGENT_SHADOW_EFFECTIVE_CONCURRENCY. Use the flags experiments_enabled, experiment_dynamic_enabled, experiment_tick_seconds, experiment_completed_grace_seconds, verdict_min_n, verdict_min_pairs and experiment_shadow_effective_concurrency. A host .env or .env.local entry for any of these vars is now silently ignored (compose no longer passes them through). The dry-run stack's refill tick goes from 15 s (env) to the flag default 30 s; set `scripts/flags.sh set agent experiment_tick_seconds fast` for 10 s.
* **agent:** `AGENT_INFERENCE_BACKEND`, `_MODEL`, `_EFFORT`, `_TIMEOUT_SECONDS`, `AGENT_EFFECT_WINDOW_SECONDS`, `AGENT_AUTONOMOUS_REWATCH_INTERVAL_SECONDS`, `_REWATCH_TIMEOUT_SECONDS`, `_REVERT_COOLDOWN_SECONDS`, `AGENT_PROBE_DECISIONS` are no longer read.
* `DEBUG` (pairing) and `OTEL_GRPC_CLIENT_SPANS` no longer have any effect.
* remove chaos fault injection (#1322 item 11) ([#1486](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1486))
* **flag-service:** in-memory flag service as flagd's only sync source; every writer moved, file mechanisms deleted (UC-053) ([#1417](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1417))
* **observability:** remove the Prometheus container ([#1449](https://github.com/WatchMeJoustMyFlags/JoustMania/issues/1449)) (#1462)
